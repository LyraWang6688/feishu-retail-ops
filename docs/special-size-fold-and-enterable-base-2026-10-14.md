## 三、展示规则（新口径）

1. ⭐ **有货的码**（不管是普通码还是**特殊码**）⇒ **完全正常展示** ✓（现货区，展开 ✓）
2. ⭐ **缺货的普通码** ⇒ 照旧正常展示 ✓（预订区 ✓，**与今天一致** ✓ 不折叠 ✗）
3. ⭐ **缺货的特殊码** ⇒ **收进「特殊码」折叠块** ✓
   - 用**浏览器原生 `<details><summary>`**（零 JS ✓）· **默认收起** ✓ ⇒ **不可见 + 不占布局高度** ✓
   - `<summary>` ≥ **44px** ✓ · 原生点击即时生效 ✓ · 展开后**不自动收回** ✓ · 刷新回默认收起 ✓
   - ⭐ **按男女鞋各自一块**（女鞋块只放女鞋的特殊码 ✓ 男鞋块只放男鞋的 ✓ 同页不混 ✗）
   - 折叠块里的条目**与外面同规则**（缺货 ⇒ 标缺码 ✓ / 预订 ⇒ 归预订 ✓）——⚠️ 她**没有**就这条给过口径，
     这是**待她确认**的临时口径（Lead 转她确认）
