## 五、顺带看到的两个小变化（和提示词有关）

1. 「行为管理」的**单选选项变多了**：「库存方向」= 增加 / 减少 / 不影响 / **按明细角色**；
   「资金方向」= 收入 / 支出 / 不影响 / **按结算状态**。
   ⇒ 「**按明细角色**」这种值一旦被用上，按「库存方向」汇总就更不可能对 ——
   v3 提示词里「禁止按库存方向汇总」那条更有必要留着。
2. 「货品信息」的「**编号**」现在是**公式列**（type=20，内容仍是 `货号|颜色|类别`），
   不再是普通文本列。对页面没影响（我们已改成在「库存键」上匹配），
   但如果以后要跨表按编号匹配，记得它是公式。
