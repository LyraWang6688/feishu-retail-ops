> 她 2026-10-08 晚看完预览后的原话（逐字）：

⇒ 于是**去掉了先前那版的"第 1 列分类名（销售-预定）"**，改成：

| 区域（= 块标题） | 每块的行 |
| --- | --- |
| `【预定】` / `【现货待收】`（销售区，各自一块）· `【采购】未到货的报货批次：N 批` | 一行 = 一个 `column_set`：**第 1 栏文字说明**（加粗货号+尺码 · 待收金额/已付清）｜ **第 2 栏「查看话题」按钮** |

- 列宽 `4 : 1`；按钮 = `{tag:'button', width:'fill', behaviors:[{type:'open_url', default_url}]}`；
- **深链缺失 ⇒ 只出第 1 栏**（不给点不动的按钮、不留空壳），仍计入脚注；
- **货号/尺码读不出来 ⇒ 占位「（未读到货号/尺码）」**（绝不静默丢这一行）；
- 空区域整块（含它前面那条分割线）不出现；
- 文案统一「**查看话题**」（`linkText` 也从「查看原话」改过来了）；
- 配置先行：`card.rowTextParts / rowTextSeparator / missingItemText / purchaseRowTextParts / buttonText / columnWeights`
  （`config/pendingDealPush.js`，占位符在启动时校验）。
