# 打印小助手（店里那台 Windows 电脑）

**它干什么**：你（或店员）在**手机上**点【打印这一款】→ 服务器把标签画成 PDF →
**这台电脑**把 PDF 送进 USB 标签打印机。这台电脑**不用一直开着**：关着的时候任务会排队，
**一打开就会自动把排队的那几张打出来**。

> 这一份是给**这台电脑**的操作说明。服务器那一侧不用你管。

---

## 📌 给家人用的一页说明（爸妈看这一页就够了）

**平时只要做一件事：双击桌面上的「打印小助手」图标。**

| 你会看到 | 是什么意思 | 要做什么 |
| --- | --- | --- |
| 桌面上有个叫「**打印小助手**」的图标 | 这就是开关 | **双击它**就行，别的都不用管 |
| 弹出一个小黑窗口 + 浏览器自动打开一个网页 | 说明它起来了 | **黑窗口别关**（可以最小化）；网页上会写「**打印电脑在线**」 |
| 网页上写「**未连接（任务已排队）**」 | 现在没连上服务器 | 等一会儿，或把黑窗口关掉再双击一次图标；任务不会丢，连上就自动补打 |
| 双击后网页写「**已经在运行了**」 | 它**早就在跑了**（你点了第二次） | **什么都不用做**，直接看那个网页（不会重复打印、也不会开第二个） |
| 手机上点了打印，标签机不出纸 | 打印机没开 / 没纸 / USB 松了 | 看网页上的**红字原因**，把黑窗口**拍张照**发给女儿 |
| 黑窗口里一堆看不懂的字 | 那是给技术同事看的日志 | **拍张照**发给女儿就行（也可以把这个文件夹里的 `helper.log` 发给她） |

> ✅ **放心点**：连点好几次也**不会重复打印**。
> 网页上如果写「刚刚已经发过一次」，就说明**系统已经拦住了**，不用再点。

**女儿让你装/卸图标时用这几个**（她一般会自己弄，这里备查）：

| 双击这个 | 作用 |
| --- | --- |
| `install-desktop-shortcut.bat` | 在**桌面**放「打印小助手」图标 |
| `uninstall-desktop-shortcut.bat` | 把桌面图标拿掉 |
| `install-autostart.bat` | 设成**开机自动启动** |
| `uninstall-autostart.bat` | 取消开机自动启动 |

> ⚠️ 这几个 `.bat` 文件里**只有英文**（这是有意的：中文写在 bat 里，换行/编码一不对就会报一屏乱命令）。
> 它们跑起来之后，**中文提示都是程序（`helper.js`）打出来的**，所以你是能看懂中文提示的。

## 一、第一次装（只做一次，约 5 分钟）

### 1. 装 Node.js

1. 打开 <https://nodejs.org/> → 下载 **LTS** 版本（Windows 安装包）。
2. 一路「下一步」装完（不用改任何选项）。

> 装完后，双击 `start.bat` 如果还提示"需要先装 Node.js"，就把这个窗口关掉**重新双击一次**。

### 2. 装 SumatraPDF（便携版，免安装）

1. 打开 <https://www.sumatrapdfreader.org/download-free-pdf-viewer> → 下载 **64-bit portable** 版（一个 `.exe`）。
2. 把那个 `SumatraPDF.exe` 放到本文件夹里（就是和 `helper.js` 同一个文件夹）。
3. 如果你放到别的地方了：打开 `config.json`，把 `printer.sumatraExe` 改成它的完整路径
   （例如 `D:\\工具\\SumatraPDF.exe` —— 注意 Windows 路径里的反斜杠要写两个）。

> **不想装 SumatraPDF？** 见文末「备选：没有 SumatraPDF 怎么办」。

### 3. 填配置

1. 把 `config.example.json` **复制**一份，改名叫 `config.json`（放在同一个文件夹里）。
2. 用记事本打开 `config.json`，改这几处：
   - `deviceToken`：填服务器 `.env` 里 `LABEL_PRINT_DEVICE_TOKEN` 的**同一个值**（找技术同事要）。
   - `printer.sumatraExe`：如果 SumatraPDF.exe 就在本文件夹里，这一行**不用改**。
   - ⭐ `printer.printSettings`：**保持默认 `["disable-auto-rotation", "center"]` 就行**（见下面「标签方向/位置不对怎么办」）。
3. 保存。

### 4. 试一下

双击 **`start.bat`**。会弹出一个黑色窗口（**这个窗口不要关**，关了就打不出来），
它自己会打开一个小页面。用浏览器打开：

**<http://127.0.0.1:8799/>**

- 上面一排会显示：**服务器连上了没有 / 长连接通不通 / 打印程序配好没有 / 当前打印参数**。
- 点【**测试打印**】：如果标签机吐出一张写着 `TEST PRINT 40x30` 的小标签，就说明**这条链路通了**。

### ⭐ 标签方向/位置不对怎么办（只改 `config.json` 一行，改完**重启小助手**）

**为什么会有这一项**：SumatraPDF **默认会把"横着的页面"自动转 90°** 去塞进纸
（官方文档里的 *auto-rotation*）。我们的标签页是 **40mm 宽 × 30mm 高**（宽 > 高）⇒ 会被它自动转，
于是「邯美皮鞋」就顺着**短边**了 —— 而且"不转就塞不下"这件事**根本不存在**（是被转了才塞不下）。
所以默认帮你加了 `disable-auto-rotation`（**关掉自动旋转**）。

**两个毛病、两项默认值**：
- `disable-auto-rotation` = **别自动转**（不然"横着的页面"会被转 90°，品牌就顺着短边了）；
- `center` = **水平居中**（页面比可打印区域小的时候，SumatraPDF 默认**靠左放** ⇒ 右边一大片空白）。

打开 `config.json`，找到 `printer` 这一块，改**这一行**：

```json
"printSettings": ["disable-auto-rotation", "center"],
```

| 打出来的样子 | 就把这一行改成 | 说明 |
| --- | --- | --- |
| **方向和位置都对** | `["disable-auto-rotation", "center"]` | ⭐ 默认值，推荐 |
| 方向对、但**贴左不居中** | `["disable-auto-rotation", "center"]`（就是默认） | `center` 已经管这个；还没居中就先重启 |
| **被裁边**（内容超出可打印区域） | `["disable-auto-rotation", "center", "noscale"]` | `noscale` = 按实际尺寸、不许它再缩放 |
| 反了 180°（上下颠倒） | `["disable-auto-rotation", "center", "rotate=180"]` | 「自动旋转」之上再转 180° |
| 反了 90° | `["disable-auto-rotation", "center", "rotate=90"]` | 也试一下 `rotate=270` |
| 想回到 SumatraPDF 的老行为 | `[]` | 空数组 = 不加这一档（不推荐：又会被转 90°、还不居中） |

> 🧰 **排障顺序**：先 `center`（位置）→ 还偏就加 `noscale`（防缩放/裁边）→ 方向还不对再加 `rotate=180/90/270`。

- ⚠️ **改完要重启**小助手（关掉那个黑窗口，再双击桌面图标）。
- ⚠️ 里面**不能**有逗号和空格（多项用**两个引号+逗号**隔开，像上面的例子），也不能重复。
- 改错了不会静默：黑窗口/网页上会**指出是哪个字段**错了。
- 打开小页面（<http://127.0.0.1:8799/>）能看到**当前用的打印参数**，排障时一眼就知道有没有生效。

## 二、平时怎么用

1. **双击桌面上的「打印小助手」图标**（= 双击文件夹里的 `start.bat`，两个都行）——
   **黑色窗口留着别关**（可以最小化），它会**自动打开状态页**给你看「在线 / 未连接」。
2. 手机上点【打印这一款】/ 工作台点【打印到店里那台电脑】→ **几秒内**标签机就出纸。
3. 要停下来：直接关掉那个黑色窗口。
   ⚠️ **重复双击不会出问题**：第二个只会把状态页打开，然后自己退出（不会重复打印）。

## 三、设成开机自启（可选，但推荐）

双击 **`install-autostart.bat`** → 以后一开机它就自己跑（**最小化启动**，不打扰你）。

取消自启：双击 **`uninstall-autostart.bat`**；
或者按 `Win + R` → 输入 `shell:startup` → 回车 → 把里面的「打印小助手」删掉。

## 四、出问题了怎么查（按顺序看这 3 个地方）

| 现象 | 先看哪 | 常见原因 |
| --- | --- | --- |
| 手机上显示「未连接（任务已排队）」 | 小页面顶部 | 黑窗口没开 / 关掉了 ⇒ 双击 `start.bat`；任务不会丢，打开就补打 |
| 打不出来，手机上有「失败」 | 小页面上的**失败原因**（也在最近任务那一行） | 打印机没开 / 没纸 / USB 松了 / SumatraPDF 路径不对 |
| 小页面顶部有黄条 | 黄条上写的字段名 | 配置没填全（`deviceToken` / `sumatraExe` 路径不存在）—— 按黄条改 `config.json`，然后重启 `start.bat` |
| 想再打一次刚才失败的那张 | 小页面最近任务那一行的【**补打**】 | 补打会**新建一条任务**，原始记录不会被改掉 |

**日志**：黑色窗口里每一行都是一条 JSON（例如 `print_helper.job.printed`），
**同时**存在同目录的 `helper.log` 里（超过 256KB 会自动轮转成 `helper.log.1`，不会撑爆硬盘）——
**拍窗口**或者**把 `helper.log` 发出来**都行。

> ⚠️ **绝对不会重复打印**：这份程序在本地记着"哪些已经打过了"。
> 上次打印**打到一半断电**这种情况，它**不会自动重打**（怕打重），
> 手机上会显示一条失败：「上次打印结果未知（可能已经打出来了）」——
> 你确认之后再在小页面点【补打】。

## 四·五、电脑会不会"睡过去"？小助手断了怎么办（**她问的那件事**）

> 业务负责人 2026-10-12 问：「小助手会断线是因为我的电脑**锁屏**了吗？」
> 「能不能让小助手**开着就保持后台运行**，这样我**就不用让电脑一直亮屏**了？」

**先把因果关系说清（这是最关键的一句）：**

- **锁屏不会断；睡眠/休眠才会断** ⭐
  —— 锁屏只是把画面盖住，网络和程序都还在跑；**睡眠（或休眠）**会把程序挂起，
  这时小助手连服务器的长连接才会断（日志里会出现 `print_helper.sse.disconnected`）。
  她那次"空了约 15 分钟"就是电脑睡过去了（16:54:33 断 → 17:09:53 才回来）。

**首选：什么都不用做（小助手自己会把"睡眠"拦住）** ⭐

- 小助手一启动就会调系统的 `SetThreadExecutionState`（`ES_CONTINUOUS | ES_SYSTEM_REQUIRED`）
  —— 效果就是**这台电脑不会进入睡眠**，于是**长连接不断、随时点随时出纸**。
- ⚠️ **只防睡眠，不拦关屏**：**屏幕可以关** ✓（该省电就省电；她说的就是"不用一直亮屏"）。
- 🔎 **怎么确认"防睡眠=开"**：打开状态页 `http://127.0.0.1:端口/`，看那一行
  **「防睡眠：开（电脑不会睡；屏幕可以关）」** ✓；日志里也会有一条
  `print_helper.anti_sleep.enabled`。
- ⚠️ 如果显示的是「关（没起来）」，说明这台电脑上调不通（少见）⇒ 按下面的**手动兜底**做一遍即可；
  **它不会影响打印**（只是"电脑可能还是会睡"）。
- 小助手还会顺手试一下 `powercfg /change standby-timeout-ac 0` 作兜底：
  ⚠️ 这条**需要管理员权限**、而且**不是**每台电脑都允许 ⇒ 失败**只记一条日志**（`print_helper.powercfg.skipped`），
  **不会报错、也不会影响打印**；失败时按下面的手动兜底做（那几步**不需要管理员**）。

**手动兜底（一分钟，Windows 设置里点一下）：**

1. **设置 → 系统 → 电源和睡眠 → 睡眠 = 从不** ⭐
   （"接通电源"和"使用电池"两栏都改成**从不**；笔记本**接通电源**那一栏也要改）
2. ⚠️ **合盖动作**也要改成"**不操作**"：控制面板 → 电源选项 → 选择关闭盖子的功能 →
   **接通电源时：不采取任何操作**（否则**合盖 = 直接睡**，前面做的都白搭）
3. ⚠️ 注意：**手动点睡眠仍会断** —— 系统 API 拦不住"你自己点的那一下"（点了睡就要等它醒）。
   同理，**拔掉电源**、**长按电源键**这类操作也会断。

**开机自启（省得每次自己去双击）** ⭐

- 已经有：`install-desktop-shortcut.bat`（桌面图标）。
- 让它**开机自己起来**：双击 **`install-autostart.bat`**（`config.json` 里 `openStatusPageOnStart`
  为真时，开机会自动把状态页弹出来，一眼就能看到"打印电脑在线 / 未连接"）。
- 不想要了就双击 `uninstall-autostart.bat`。

**断了会自愈（2026-10-12 加）：**

- 电脑**从睡眠里醒过来**、或**网络恢复**的那一刻，小助手会**立刻重连**（不再傻等重连退避）。
- 日志里会写清**断了多久**：`print_helper.sse.disconnected` 带 `since_disconnected`（例：`断线已 15 分钟`），
  醒来那一下还会有一条 `print_helper.wake.detected`。

**关于"要不要装成 Windows 服务"：不用装** —— 服务**也拦不住睡眠**，而且服务里**拿不到默认打印机**，
装了反而更容易出问题。所以这里走的是"小助手自己防睡眠"这条路。

## 五、备选：没有 SumatraPDF 怎么办

打开 `config.json`，把打印方式改成下面三种之一：

- **`"mode": "dialog"`（最简单的备选）**
  用系统默认的 PDF 程序打印。**缺点**：每打一次都会**弹出打印对话框**、要你点一下确认，
  所以适合"偶尔用"，不适合天天用。
- **`"mode": "command"`（有别的打印工具时）**
  ```json
  "printer": {
    "mode": "command",
    "command": "C:\\\\你的工具\\\\打印工具.exe",
    "args": ["/print", "{file}"],
    "printTimeoutMs": 60000
  }
  ```
  `{file}` 必须保留 —— 它会被换成那一份 PDF 的实际路径。

> 改完记得**重启 `start.bat`**（配置只在启动时读一次）。

## 六、这几个文件分别是什么

| 文件 | 作用 |
| --- | --- |
| `helper.js` | 程序本体（Node，零依赖） |
| `config.json` | **你的配置**（不填就没法用）；从 `config.example.json` 复制 |
| `config.example.json` | 配置样例（带注释说明） |
| `start.bat` | 双击运行（= 桌面图标指向的就是它） |
| `install-desktop-shortcut.bat` | 在桌面放「打印小助手」图标 |
| `uninstall-desktop-shortcut.bat` | 拿掉桌面图标 |
| `install-autostart.bat` | 设置开机自启 |
| `uninstall-autostart.bat` | 取消开机自启 |
| `state.json` | 本地台账：记着"哪些已经打过了"（**别删**，删了就有重复打印的风险） |
| `downloads/` | 临时放下载下来的 PDF（打完自动删） |

## 七、安全说明

- 那个小页面**只监听本机**（`127.0.0.1`），局域网/外网都访问不到。
- 设备令牌只写在**这台电脑**的 `config.json` 里，不发往任何第三方。
- 这台电脑只跟我们的服务器通信（`config.json` 里的 `serverBaseUrl`）。
