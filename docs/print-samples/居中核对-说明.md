# 标签内容的“页内居中”核对（2026-10-12）

她反馈「方向对了，但沿长边没有居中」。**先量再改**，结论是：

- ✅ **左右本来就是对称的**（默认产物：左 1.50mm / 右 1.63mm，差 **−0.13mm** ≈ 1px）
- ⚠️ **上下不对称**（上 1.63mm / 下 5.88mm，差 **−4.25mm**）—— 内容整体偏上

## 怎么用

`artifact.contentOffsetXMm` / `contentOffsetYMm`（mm，**0.5 的整数倍、±5 以内**，默认 0）：
把**整幅内容**在页内左右/上下平移 —— **只动内容、裁切线留在纸边**、**不改字号与二维码尺寸**。

- 若她说的“长边”是页面的**竖轴**（标签进纸方向转了 90°）⇒ `contentOffsetYMm = 2` ⇒ 上下各 3.75mm（正）；
- 是横轴 ⇒ 保持 0（本来就对称）。

⚠️ 本组图是**页面坐标**（没做纸面 −90° 还原），因为这次核对的是"内容在页面里"的位置。
