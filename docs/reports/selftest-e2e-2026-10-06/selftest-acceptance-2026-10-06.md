## 验收标准（业务口径，5 条）

| # | 应该发生什么 | 判据（脚本自动核对） |
| --- | --- | --- |
| ① | 出 1 张「采购退货单」，数量 = N（本次 N=2） | 「单据信息」新增行，合计数量 = N；涉及尺码数 = 行数 |
| ② | 「库存流水」新增 N 行，行为 = 采购减少 / STOCK_PURCHASE_DECREASE | 新增 N 行、每行变动数量 = 1、库存行为编码 = STOCK_PURCHASE_DECREASE |
| ③ | 「实时库存」对应尺码减少（减到 0 的行应消失） | 消失行数 = N；每个涉及尺码的剩余行数 = 原有行数 − 本次退掉的行数；减到 0 的尺码一行不剩 |
| ④ | 报货记录「处理状态」= 已生成申请 + 「关联采购申请」回填 | 处理状态 = 已生成申请；关联采购申请 = 本批单据信息行的 record_id 集合 |
| ⑤ | 往群里发 1 张退货单图（+ @经办人） | 图片消息 1 条、文字消息 ≥1 条且含 `<at user_id=...>`；图写回「单据信息」附件 |

**结论口径**：5/5 达标；任何一条不成立 → 未达标，写出差在哪 + 建议怎么改。
