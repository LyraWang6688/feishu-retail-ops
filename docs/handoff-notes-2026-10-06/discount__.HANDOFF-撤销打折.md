## 正确的规则**只有两条**（照这个改 ✓）
```
① ⭐ **成交金额 = 用户说的钱**
   「119 元腰带，是收到了 100 元微信」→ **成交金额 = 100** ✓
   ⚠️ 这里的 "119" **只是"它属于哪一款"的标识** ✓
      （业务负责人原话：「39 的和 49 的就是不一样的东西」✓）
      → **它跟钱无关** ✗ · **不落库** ✗ · **不参与任何金额计算** ✗
   ⚠️ 若用户**只说了某个数、没说收多少** ✗ → 那时才把那个数当成交金额 ✓（原行为 ✓）

② ⭐ **未收款只在用户明说"欠"时才生成**
   · 用户**没说"欠"** → **绝不生成** ✗ ⭐（**这就是本次唯一要修的 bug** ✓：
     现在 `salesOrderService.js:134-136` 是"成交>已收就自动补"✗ → 它自作主张 ✓）
   · 用户**说"欠 19"** → 生成未收款 19 ✓
```
