## 2. 采购页（Procurement）

### 2.1 页面定义（来自 Base「前端页面」表）

```text
供应 → 录单 → 采购
三个子 tab：补货 / 上新 / 扫一扫；**本轮只做补货 + 上新，扫一扫最后处理**
tab 切换保留当前会话已选数据
点击「提交」后才统一写入
提交复用既有采购链路，不新增服务端草稿表/写路径
```

**补货**

- 近 3 天销售 + 库存数量 = 0；
- 按编号/尺码分组；
- 交易类型区分现货 / 预订；
- 预订必补、默认已选；现货按需选择。

**上新**

- 今天新增货品（上架日期 00:00 后）；
- 按记录ID分组（内部，不展示）；
- 卡片只展示 货号·颜色 + 今日 HH:mm 新增 + 供应商；
- 普通码默认 1 双；特殊码默认 0 并折叠。

**扫一扫（本轮最后处理，先不考虑）**

- 本轮只做补货 + 上新；tab 可保留视觉入口但占位/禁用。
