# 「货品 → 标签打印」的入口结构（2026-10-14 晚 · 业务负责人逐字）

> 她逐字：「货品 tab 里的**打印标签支持两类**，一类是**单个打印**，一类是**批量打印**，
>  **单个打印支持扫码打印和选择编号打印**。」

## 一、要的结构（验收线）
```
货品 → 标签打印
 ├─ ⭐ 单个打印
 │    ├─ ⭐ 扫码打印      （她按一下 ⇒ 弹飞书扫一扫 ⇒ 扫到哪一款就打哪一款的标签 ✓）
 │    └─ ⭐ 选择编号打印   （手填/选 编号或货号 ⇒ 打这一款 ✓）
 └─ ⭐ 批量打印          （按条件挑一批 ⇒ 打一批 ✓）
```

## 二、现状（我核过真源 ✓）
| 入口 | 现状 |
|---|---|
| **选择编号打印** | ✅ **已有**（`config/domains.js` 的 `product-labels` = 表单 `编号/货号` ⇒ 跳 `/workbench/label-print.html?keyword=…` ✓ 预填筛选 ✓ 不新增请求 ✓） |
| **批量打印** | ✅ **已有**（同一条 `links` 里的「批量打印」⇒ 打开标签打印页，不带 keyword ✓ 那一页有筛选 + 队列 ✓） |
