## 一、版式（40×30mm 横版，203dpi）

```
        邯美皮鞋                 ← 品牌：**顶部居中**（跨整张）
┌────────┐  0225  棕色          ← 第一行：**货号 + 颜色**（货号大字在前）
│ 二维码  │  ¥198               ← 第二行：**单价**
└────────┘  36₁ 37₁ 38₁        ← 尺码区：**从小到大**，角标=该尺码数量
            39₁ 40₁
```

- **二维码 15×15mm**，内容 = `https://hm.bamamei.online/s/{编号}`（编号 = `货号|颜色|类别`，中文 URL 编码）
- **不印「品类」**（她 2026-10-08 明确：「我只能放货号、颜色，然后单价，然后尺码。放品类了吗？没放品类啊」）
- 不印「所属状态」、不印底部小字（开关留着）
- **尺码只印有库存（数量>0）的**；一行放不下自动换行（最多两行），排不下在行尾补 `…`
- 数量角标 = 真 `<span>` 小字下沉，**不是 Unicode 下标字符**
- A4 每页 **4 列 × 9 行 = 36 张**（留白 6mm）

## 二、数据来源

| 项 | 来源 |
| --- | --- |
| 编号（分组键 + 二维码内容） | 「实时库存.库存键」前三段 = `货号\|颜色\|类别` |
| 颜色 | 「实时库存」的「颜色」关联列 |
| 单价 | 「货品信息.单价」（按编号取；取不到**照发标签**、不印价格、计数 + warn） |
| 品牌 | 配置里的 `邯美皮鞋`（可切换为表里的列） |
| 尺码数量 | 「实时库存」按编号聚合（只数有货的） |
