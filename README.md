# 零售数智经营助手

> 门店每天的对账、盘点、补货，不用再开 Excel 手工汇总 —— 扫一下，账自己落到飞书里。
>
> **给谁用**：线下零售门店的店长 / 区域运营
> **它做什么**：扫码销售、补货退货、库存、采购验收、资金对账，全部落进飞书多维表格
> **它凭什么靠得住**：后端只执行确定性规则 —— 写账、扣库存这类决定不交给模型

面向线下零售与小型企业的飞书数智经营底座。邯美当前部署名称为「邯美数智经营工作台」，代码仓库名为 `feishu-retail-ops`。

> **现状（2026-10-17，业务负责人口径）**：系统由**飞书**承载，**飞书多维表格是唯一事实源**，后端是**确定性执行引擎**（校验 / 幂等 / 写表 / 联动）。**数据录入只有两种入口**：① **扫一扫页面的前端 UI 表单**；② **飞书多维表格表单**。群聊 / 私聊 / 语音转文字 / 拍照识别 / 微信小程序等历史入口均已退场并从代码删除，当前**没有**其他录入方式。

## 1. 项目简介

- **扫一扫页面**：店内高频录入（销售 / 补货 / 库存 / 退货）。销售是「货品页 → 资金页 → 成功页」三步；补货 / 退货与销售都支持**一单多货**，且都是**异步**（先回成功页，后台写库）。
- **网页工作台**：统一处理入口 —— 销售订单交割 / 售后 / 补充样品、库存手工调整、货品上新与标签打印、采购验收与供应商信息等。
- **飞书多维表格**：业务事实的落点（货品 / 销售 / 采购 / 库存 / 资金 / 行为配置）。
- **后端**：只做「解析后的确定性执行」——不把写账、扣库存这类决定交给模型。

历史入口（均已删除，仅供追溯）：微信小程序（2026-10-01 退役）、飞书私聊机器人（2026-10-07 删除）、群聊销售文字入口（2026-10-12 退场）、语音转文字 / 拍照识别 / 群话题到货核对（已随对应链路退场）。当前运行期**没有 AI 解析调用**（文字/图片/意图解析都不再参与业务）。

## 2. 核心功能（现行）

- **扫码销售**：一单多货、逐件实收、资金页金额必填（可填 0，不要求等于货品合计）、异步写库、统一极简成功页；「全付 / 部分付 / 未付」由金额自动定档。
- **补货 / 退货**：一单多货、异步、按供应商分组出单（一个批次号 + 多行明细）；退货同样走扫码页。
- **库存**：实时库存「一双一条」，按「编号 + 尺码 + 所属状态」操作；普通码全展示、特殊码有货才展示；手工调整 / 换季调整在工作台。
- **采购**：扫一扫「补货」生成采购申请；工作台「采购 → 验收」做**到货验收**（只认「报货」批次，**退货不需要验收**）并按实到数量加库存。
- **资金**：一张销售单可关联多笔收款；少收 / 未收自动补一条【未收款】差额。
- **标签打印**：工作台「货品 → 标签打印」（扫码打印 / 按编号打印 / 批量打印）。
- **工作台销售订单**：待交割（货没交 / 钱没交 / 钱货都没清）、售后、补充样品（细化见 issue #798）。

## 3. 技术栈

- **交互入口**：
  - 扫一扫页面（服务端渲染 + 少量 JS 动态交互）
  - 飞书多维表格表单
  - 飞书网页工作台（前端页面 + `/api/workbench/*`）
- **后端**：Node.js (>=20) + Express
- **部署方式**：腾讯云轻量应用服务器 + Nginx + PM2
- **表格服务**：飞书多维表格 (Feishu Bitable) API
- **AI**：当前运行期**没有**解析调用；即使环境里保留模型配置，也没有业务读取点（历史链路见文档索引的归档区）

## 5. 快速开始

1. 安装依赖并启动后端
   - `cd server && pnpm install`
   - `pnpm run dev`
2. 入口说明：业务数据通过**扫一扫页面的 UI 表单**或**飞书多维表格表单**录入；工作台负责后续处理与查询，不承担「私聊 / 群聊文字录入」。
3. 生产环境默认后端地址为 `https://api.bamamei.online`。
4. 轻量云服务器部署（服务器目录与 PM2 进程名保留兼容名称，见 [飞书 V1 运行与排查](docs/feishu-v1-operations.md)）
   - 服务器安装 `Node 20`、`pnpm`、`pm2`、`nginx`
   - `cd /opt/box2bitable/server && pnpm install`
   - `pm2 start ecosystem.config.js`
   - `nginx` 反向代理到 `127.0.0.1:5000`
   - `certbot --nginx -d api.bamamei.online`
5. 日志排查（可选）
   - 后端日志是结构化 JSON（`server/src/utils/logger.js`），可按事件名过滤 PM2 日志
